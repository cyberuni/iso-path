## Contribute

```sh
# after fork and clone
pnpm install

# begin making changes
git checkout -b <branch>
pnpm watch

# after making change(s)
pnpm verify
pnpm cs   # add a changeset if the published package changes
git commit -m "<commit message>"
git push

# create PR
```
